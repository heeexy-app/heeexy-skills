# HEEEXY Skills

Free [Agent Skills](https://agentskills.io) for makers and print-on-demand sellers, by [HEEEXY](https://heeexy.app). They work with Claude Code, Codex, Cursor and any agent that reads `SKILL.md`.

| Skill | What it does |
|---|---|
| [vector-illustrator](skills/vector-illustrator/SKILL.md) | Draws clean, editable SVG logos, stickers, icons and Cricut cut files |
| [etsy-listing-writer](skills/etsy-listing-writer/SKILL.md) | Writes Etsy titles, 13 tags, descriptions and alt text for digital downloads |
| [pod-design-brief](skills/pod-design-brief/SKILL.md) | Turns a print-on-demand idea into print specs, AI image prompts and a checklist |
| [pinterest-pin-writer](skills/pinterest-pin-writer/SKILL.md) | Writes Pinterest pin titles, descriptions, alt text and boards for search |
| [cricut-cut-file-prep](skills/cricut-cut-file-prep/SKILL.md) | Checks and fixes SVG cut files for Cricut and Silhouette |

## Install

With the [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add Sofiamastery/heeexy-skills
```

Or copy a folder from `skills/` into `.claude/skills/` in your project (or `~/.claude/skills/` for every project) and restart your agent.
